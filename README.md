# Programmers SQL Study

프로그래머스 SQL 고득점 Kit 문제를 MySQL로 풀이하며
SQL 기본 문법과 데이터 조회/집계 능력을 학습한 저장소입니다.

## Environment

- MySQL
- Programmers SQL Kit
- VS Code

## Contents

| Category | Description |
|---|---|
| SELECT | 데이터 조회 및 조건 처리 |
| SUM, MAX, MIN | 집계 함수 |
| GROUP BY | 그룹별 집계 |
| IS NULL | NULL 처리 |
| JOIN | 테이블 결합 |
| String, Date | 문자열 및 날짜 처리 |

## Learning Goals

- SQL 기본 조회 문법 이해
- 집계 함수 및 GROUP BY 활용
- JOIN을 통한 관계형 데이터 조회
- 날짜/문자열 데이터 처리
- 다양한 SQL 문제 해결 능력 향상

## Commit Convention

커밋 메시지는 작업 내용을 쉽게 파악할 수 있도록 아래 규칙을 사용합니다.

| Type | Description |
|---|---|
| `solve` | 새로운 SQL 문제 풀이 추가 |
| `fix` | 잘못된 SQL 쿼리 또는 풀이 수정 |
| `refactor` | 정답은 동일하지만 SQL 구조 및 가독성 개선 |
| `docs` | README 및 학습 내용 수정 |
| `chore` | 폴더 구조, 설정 등 기타 작업 |
