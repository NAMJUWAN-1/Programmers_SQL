# Programmers SQL Study

프로그래머스 SQL 고득점 Kit 문제를 MySQL로 풀이하며
SQL 기본 문법과 데이터 조회/집계 능력을 학습한 저장소입니다.

## Environment

- MySQL
- Programmers SQL Kit
- VS Code

## Contents

| Category | Description |
|---|---|
| SELECT | 데이터 조회 및 조건 처리 |
| SUM, MAX, MIN | 집계 함수 |
| GROUP BY | 그룹별 집계 |
| IS NULL | NULL 처리 |
| JOIN | 테이블 결합 |
| String, Date | 문자열 및 날짜 처리 |

## Learning Goals

- SQL 기본 조회 문법 이해
- 집계 함수 및 GROUP BY 활용
- JOIN을 통한 관계형 데이터 조회
- 날짜/문자열 데이터 처리
- 다양한 SQL 문제 해결 능력 향상
